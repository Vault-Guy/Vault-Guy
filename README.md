## Featured Projects

### [PCA-Based Statistical Arbitrage](https://github.com/Vault-Guy/replication-portfolio-arbitrage-mvp)
Walk-forward synthetic asset replication and mean-reversion research across U.S. equities, Russian equities, and cryptocurrencies.

- PCA-based synthetic replication with rolling walk-forward estimation
- causal z-score signals and transaction-cost-aware backtesting
- parameter grid search and robustness analysis
- replication diagnostics: R², tracking error, ADF tests, and spread half-life

### [Bank Volatility Modelling](https://github.com/Vault-Guy/bank-volatility-modelling)
Econometric research on conditional volatility and downside risk for Russian banking and financial instruments.

- ARMA-GARCH and EGARCH models with Student-t innovations
- stationarity, residual, and ARCH diagnostics
- 95% and 99% Value-at-Risk estimation
- Kupiec and Christoffersen VaR backtests

### [Optimization Methods in Machine Learning](https://github.com/Vault-Guy/optimization-methods-in-machine-learning)
Course materials for a university-level Optimization Methods in Machine Learning course developed and taught at HSE University.

- lecture notes and seminar problem sets
- Python-generated figures and laboratory materials
- LaTeX sources and automatically built PDFs
- GitHub Actions workflow for reproducible course builds
